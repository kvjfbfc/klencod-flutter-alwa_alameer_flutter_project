# تطبيق علوة الأمير — Flutter Hybrid

هذا المشروع يحوّل موقع نظام المخزون والمبيعات إلى تطبيق Android باستخدام Flutter WebView، مع طبقة Android أصلية للهوية، مؤشر التحميل، زر إعادة التحميل، معالجة أخطاء الاتصال، والرجوع داخل سجل صفحات الموقع.

**رابط الموقع:** https://inventory-and-sales-jgrk.bolt.host/

## المتطلبات
- Windows 10/11 64-bit.
- Flutter SDK حديث (يوصى بـ Flutter 3.38 أو أحدث بسبب إصدار webview_flutter المستخدم).
- Android Studio مع Android SDK وPlatform Tools.
- اتصال إنترنت عند تنزيل الحزم وعند استخدام الموقع.

## أسرع طريقة لإنشاء مشروع Android كامل
1. فك ضغط الملف.
2. افتح مجلد `alwa_alameer_flutter`.
3. افتح PowerShell داخل المجلد.
4. نفّذ:

```powershell
Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
.\create_project.ps1
```

ينشئ السكربت مشروع Flutter كاملاً باسم `alwa_alameer`، ثم ينسخ ملفات التطبيق ويضيف صلاحية الإنترنت واسم التطبيق العربي.

## تشغيل التطبيق على الهاتف
فعّل USB debugging على الهاتف، وصله بالكمبيوتر، ثم:

```powershell
cd alwa_alameer
flutter devices
flutter run
```

أو شغّله على محاكي Android من Android Studio.

## استخراج APK
من داخل مجلد المشروع:

```powershell
flutter build apk --release
```

الملف الناتج:

`build\app\outputs\flutter-apk\app-release.apk`

انقله إلى الهاتف وثبّته. إذا منع Android التثبيت، اسمح بالتثبيت من هذا المصدر في إعدادات الأمان.

## إعدادات مهمة
- اسم التطبيق: علوة الأمير.
- معرف الحزمة: `com.alameer.inventory.alwa_alameer` (ينشئه أمر flutter create بحسب org واسم المشروع).
- الرابط الافتراضي محدد داخل `lib/main.dart`.
- تخزين الجلسة وبيانات الموقع يعتمد على WebView وخصائص الموقع نفسه؛ لا تحذف بيانات التطبيق إذا تريد الاحتفاظ بتسجيل الدخول.
- يحتاج التطبيق إلى الإنترنت لأن النظام مستضاف على الويب. هذه النسخة لا تحول الموقع إلى نظام يعمل دون إنترنت.

## ملاحظات قبل الاعتماد الفعلي
هذه طبقة تطبيق حول الموقع وليست إعادة برمجة لنظام المخزون. لذلك تعتمد وظائف تسجيل الدخول، حفظ الفواتير، التقارير، الطباعة، وقاعدة البيانات على الموقع والخادم.

يجب اختبار رفع الملفات وتنزيلها، اختيار الصور/المرفقات، الطباعة، وروابط واتساب على هاتف Android فعلي. دعم منتقي الملفات والتنزيلات في WebView قد يحتاج إضافة معالجة Android مخصصة بحسب طريقة تنفيذ الموقع؛ لا تعتبر هذه الوظائف مؤكدة قبل الاختبار.

إذا كان الموقع لا يحفظ البيانات بعد إغلاقه، فإن تحويله إلى WebView لن يصلح مشكلة الحفظ في الخادم أو قاعدة البيانات تلقائياً.
